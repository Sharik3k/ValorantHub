# 🎨 Дизайн та UI Features

## Офіційні кольори Valorant

Проект використовує офіційну кольорову палітру Valorant:

- **Червоний**: `#ff4655` - основний акцентний колір
- **Темно-синій (майже чорний)**: `#0f1923` - фон
- **Білий (текст)**: `#ece8e1` - основний текст
- **Сірий**: `#8a8d91` - другорядний текст

## Шрифти

- **Заголовки**: Bebas Neue (схожий на Tungsten)
- **Текст**: Inter (схожий на DIN Next)
- Всі заголовки uppercase з letter-spacing для автентичного вигляду

## Анімації та ефекти

### 1. Glitch Effect
Ефект "глітчу" при наведенні на заголовки:
```css
.glitch-text:hover {
  animation: glitch 0.3s infinite;
}
```

### 2. Hover ефекти для карток
- Плавне піднімання картки при наведенні
- Світіння червоним кольором
- Збільшення зображення всередині картки

### 3. Кнопки з анімацією
- **valo-btn**: Основна кнопка з ефектом світіння
- **valo-btn-outline**: Кнопка з ефектом заповнення при наведенні

### 4. Fade-in анімації
Всі елементи з'являються плавно з затримкою для кращого UX

### 5. Pulse Glow
Пульсуюче світіння для важливих елементів (AI-чат кнопка)

## Mobile-First підхід

### Адаптивна навігація
- На десктопі: горизонтальне меню з іконками
- На мобільних: бургер-меню з анімованим випадаючим списком
- Великі кнопки для зручного натискання пальцем

### Responsive Grid
- Мобільні: 1 колонка
- Планшети: 2 колонки
- Десктоп: 3-4 колонки

### Touch-friendly
- Мінімальний розмір кнопок: 44x44px
- Достатні відступи між елементами
- Швидкі анімації (не більше 0.3s)

### Valo Stripes
```tsx

  {/* Діагональні лінії як у Valorant */}
```

## Декоративні елементи

- Радіальні градієнти для глибини
- Діагональні смуги (stripes pattern)
- Світлові ефекти навколо важливих елементів
- Backdrop blur для навігації

## Accessibility

- Всі інтерактивні елементи мають focus states
- Достатній контраст тексту
- Семантичний HTML
- ARIA labels для кнопок

## Performance

- Lazy loading для зображень
- CSS анімації (GPU прискорення)
- Оптимізовані transition timing functions
- Мінімальне використання JavaScript для анімацій

## Як використовувати

### Кнопки
```tsx
// Основна кнопка
<button className="valo-btn">Натисни мене</button>

// Outline кнопка
<button className="valo-btn-outline">Натисни мене</button>

// З пульсацією
<button className="valo-btn pulse-glow">Важлива дія</button>
```

### Анімація появи
```tsx
<div className="animate-fade-in-up" style={{ animationDelay: '0.2s' }}>
  Контент з'явиться плавно
</div>
```

### Glitch текст
```tsx
<h1 className="glitch-text">
  VALORANT
</h1>
```
